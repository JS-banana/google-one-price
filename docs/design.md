# 设计规范（v1）

> 本文是 UI 实现的**唯一依据**。数据口径以 `docs/data-source.md` 与 `src/lib/data/` 为准；本文只规定呈现与交互。
> 与本文冲突时，以本文为准；本文未覆盖的细节，按"工具优先、低噪音、可读性最高"自行判断，并在交付说明里列出。

## 1. 定位与原则

**一句话**：帮中文用户在 10 秒内回答"这个 Google One / Gemini 套餐，在哪个区订最划算、续费会不会被坑"。
这是一张**会每小时刷新的行情单**，不是营销页。

五条原则：

1. **答案先行**：首屏就是结论（最低价是谁、多少钱），没有 Hero、没有介绍段落。
2. **首期与续费永远绑在一起**：任何出现首期优惠价的地方，续费价必须紧贴出现，并标注跳涨倍数。
3. **一个全局口径**：全站只有一个"价格口径"开关（见 §2），所有排名、高亮、最低价都跟随它。
4. **低噪音**：空值用 `·`，不写"暂无/N/A"；只在有语义的地方用色；无阴影、无渐变、无大圆角。
5. **秒开**：静态预渲染；首页零框架 JS；中文不加载 webfont。

## 2. 核心口径（全站统一）

### 2.1 价格口径（view）

| id      | 中文标签             | 定义（CNY）                 | 适用说明                   |
| ------- | -------------------- | --------------------------- | -------------------------- |
| `intro` | 首期月价             | 首期优惠价；无优惠时 = 原价 | 看"入门门槛"               |
| `year`  | **首年月均**（默认） | 首年实际付款总额 ÷ 12       | 最能反映真实花费，默认口径 |
| `renew` | 续费月价             | 续费/原价                   | 看"长期持有"               |

- 年付 SKU：一律折算为**月均**（年价 ÷ 12）参与比较，并在主价旁标 `年付` 或为原币加 `/年`。年付试用结束时计入一次完整年费，年付首年折扣取折后年费。
- 首期为 0（免费试用）：`intro` 口径下显示 `免费`，同时标注 SKU 编码的试用时长，排名时视为 0。
- 公式、优惠期数解析、年付识别等计算**只在 `src/lib/data/` 实现一次**，UI 不得自行重算。若数据层尚无对应函数，补到数据层并加测试。

### 2.2 续费跳涨标记（TrapBadge）

倍数 = 续费价 ÷ 首期价（仅对有首期优惠的报价）：

| 条件            | 显示           | 色              |
| --------------- | -------------- | --------------- |
| 首期 = 0        | `试用后 ¥X/月` | warn（朱砂）    |
| 倍数 ≥ 10       | `续费 ×195`    | warn            |
| 1.2 ≤ 倍数 < 10 | `续费 ×2.0`    | caution（琥珀） |
| 无首期优惠      | 不显示任何标记 | —               |

倍数 < 10 保留 1 位小数，≥ 10 取整。

### 2.3 USD 计价区

币种为 USD 的非美国地区，在国家名后加小标 `USD`（caution 色文字，无底色）。排名页与矩阵提供"隐藏 USD 计价区"开关（默认**不隐藏**，用 `?usd=hide` 与 localStorage 持久化），开关旁显示当前可见数 `39 / 60`。

### 2.4 数据层能力

1. 付费优惠以中文说明的期数为准，免费试用以 SKU 编码时长为准。账期、优惠时长和冲突统计见 [数据源](data-source.md)。
2. `priceFor(quote, view)` 和 `getTierRanking(id, view)` 提供三种价格口径。排名使用未舍入值。
3. 跳涨倍数、档位归类、首页提示、免费试用汇总和历史的价格异常判定在数据层计算。
4. 国家 `iso2` 用于 SVG 国旗，币种为 USD 且地区非美国时加 USD 计价标记。
5. 首页与矩阵按同一组档位定义分组：
   - `ultra`「Google AI Ultra（20x）」含 30 TB 月付、Ultra 5 折 ×3、Ultra 原价月付。
   - `pro`「Google AI Pro」含两个月付优惠档、原价月付、原价年付、原价月付（5tb SKU）和年付首年 7.5 折。
   - `plus`「Google AI Plus」含首期特价、原价月付和年付首年 7.5 折。
   - `storage`「大容量存储」含 20 TB、10 TB 月付。

## 3. 信息架构与路由

顶部主导航 5 项（文字导航，无图标）：

| 导航       | 路由                                  | 核心任务                          |
| ---------- | ------------------------------------- | --------------------------------- |
| 低价速查   | `/`                                   | 各档位全球最低，答案先行          |
| 价格矩阵   | `/matrix`                             | 60 国 × 核心档位横向比较          |
| 国家/地区  | `/countries`、`/countries/[iso3小写]` | 某区有哪些 SKU、多少钱            |
| 变动记录   | `/changes`                            | 最近监控到的新 SKU/变动           |
| 汇率与说明 | `/rates`                              | 汇率依据、计算口径、免责声明、FAQ |

另有不在导航中的档位详情页：`/tiers/[tierId]`（从首页卡片、矩阵列头进入）。
所有页面静态预渲染（SSG）。404 页简洁，提供返回首页与搜索国家入口。

## 4. 全局外壳

### 4.1 Header（桌面吸顶，高 52px，1px 底线）

- 左：字标 `G1 价目`（"G1" 用等宽字体 600，"价目" 系统中文 600；字标前一个 6×6 朱砂方点作为唯一品牌记号）。
- 中/左：主导航；当前页 = 墨色文字 + 2px 墨色下划线；其余 = secondary 色。
- 右：**元信息胶囊**（等宽小字）：`更新 11-27 14:12 · $1 = ¥6.675`，点击进入 `/rates`。时间以源数据刷新时间为准，按 Asia/Shanghai 展示。
- 移动端（<768px）：字标 + 元信息（仅时间）+ 菜单按钮；随页面滚动，菜单展开为全宽下拉列表（无动画或 120ms 透明度）。

### 4.2 口径控制条（ViewBar）

出现在首页、档位详情页、国家详情页和矩阵页。桌面吸顶于 Header 之下。

- 三态分段控件：`首期月价 | 首年月均 | 续费月价`，选中态 = surface 底 + strong 边框 + 墨色 600；控件下方或右侧一行 muted 小字解释当前口径（如"首年月均 = 前 3 期优惠 + 9 期续费，按 12 个月平均"）。
- 显示原币开关：`显示原币`（默认开）。
- 页面级附加控件放在同一条右侧（如矩阵页的搜索、USD 开关）。
- 移动端：分段控件占满宽度 3 等分，单独吸顶，约 40px 高。解释、开关及其他筛选随页面滚动。

### 4.3 全局状态的实现方式（重要）

- `view` 与 `showOriginal` 是全站状态：写入 `<html data-view="year" data-original="on">`，持久化到 `localStorage`，并支持 URL 参数 `?view=intro|year|renew` 覆盖（便于分享）。
- 在 `<head>` 放一段极小的内联脚本，在首次绘制前从 URL/localStorage 读取并设置属性，避免闪烁。
- **可预计算的内容用静态渲染 + CSS 切换**：首页、档位详情页在构建时为三种口径分别算好排序与数值并全部渲染进 HTML，通过 `html[data-view=…]` 选择器只显示当前口径的那一份。首页与档位详情无需框架水合。
- 矩阵使用 Preact island，服务端渲染默认 `year`，水合后与全局口径同步。国家详情页用原生 JS 对 SKU 组内排序、筛选和展开历史。

### 4.4 Footer

细线分隔，muted 小字两行：

- `非 Google 官方网站。价格来自 iOS App Store 监控抓取，人民币为按参考汇率折算的金额，实际扣款以 App Store 为准。`
- `数据更新：{刷新时间} · 汇率基准：1 USD = {x} CNY · 共 {N} 个国家/地区、{M} 条报价`

## 5. 页面规格

### 5.1 首页 `/`（低价速查）

自上而下：

1. **标题行**：H1 `Google One / Gemini 全球 iOS 订阅低价速查`（22px），右侧 muted 小字 `60 个国家/地区 · {档位数} 个比较档位`。不要副标题段落。
2. **ViewBar**。
3. **速览条（Answer Strip）**：一行 4 格（移动端 2×2），对应 `ultra / pro / plus / storage` 四条产品线，用细竖线分隔、无卡片底色。每格 = 产品线名（Google AI Ultra（20x） · AI Pro · AI Plus · 大容量存储）+ 当前口径下该产品线**最低的那个档位与国家**：国旗 + 中文国名 + 大号 CNY 价（等宽 24px 600，best 色）+ 一行小字（档位短名 · 原币）。点击进入对应档位页。同价优先无首期优惠的档位。
4. **档位卡片区**：按产品线分组，每组有 H2 栏目标题（上方 2px 墨色顶线，左侧 `01`、`02` 等宽编号）。组内桌面 2 列网格，强关联档位左右相邻（如"Ultra 5 折×3"旁边是"30TB 纯存储"；"AI Pro 0.1 折×3"旁边是"AI Pro 原价月付"）。每张卡见组件 §6.3。
5. **免费试用一览**：编号 `05` 的通栏表，按产品与账期列出试用时长、可展开的地区链接和续费最低地区及月价。
6. **最近变动**：最近 5 条（按国家聚合后的摘要），右侧 `全部变动 →`。

桌面布局最大宽度 1280px，左右 24px 内边距；<1024px 卡片单列。

### 5.2 档位详情 `/tiers/[tierId]`

1. 面包屑式小标题（`低价速查 / {产品线}`）+ H1 档位全名 + 口径说明（包含哪些 SKU、是否有首期优惠、优惠期数）。
2. ViewBar + 右侧 `隐藏 USD 计价区` 开关 + 可见数量。
3. **摘要行**：在售国家数、最低 / 中位 / 最高（CNY，当前口径）、最高/最低倍数。
4. **完整排名表**（RankTable，见 §6.4）：该档位所有有价国家；无此档位的国家折叠为末尾一行 `另有 25 个地区无此档位` 可展开查看名单（只列名，不占行）。
5. 页脚提示：对应 SKU ID 列表（等宽 muted，可复制）。

### 5.3 价格矩阵 `/matrix`

- 标题行 + ViewBar（附：国家搜索框（中文名/英文名/ISO3/币种，即时过滤）、`隐藏 USD 计价区`、大区 `<select>` 筛选 `全部 / 亚太 / 欧洲 / 美洲 / 中东非洲`）。
- 桌面（≥1024px）：完整矩阵（§6.5），宽度可铺满视口（左右 16px）。
- 移动（<768px）默认 **单档位榜单视图**：顶部横向可滑动的档位胶囊（单选），下方是该档位按当前口径升序的国家清单（排名 / 国旗+国名 / CNY 主价 / 原币副价 / 相对最低 +x%）。右上角 `矩阵视图` 切换按钮可切回横滑矩阵（首列压缩为国旗、ISO3 和币种，宽 76px）。矩阵保留横向滚动，纵向浏览通过页面滚动。
- 768–1023px：矩阵横向滚动，首列冻结。
- 排序状态、搜索词、大区、选中档位同步到 URL query（`replaceState`），可分享。

### 5.4 国家/地区目录 `/countries`

- 按大区分组（H2），组内紧凑多列列表（桌面 4 列、平板 3、移动 2）：国旗 + 中文名 + muted ISO3 + 币种；若该国在任一档位当前为全球第 1，名称后加 best 色小标 `最低 ×N`（N = 拿下第 1 的档位数，按默认口径 `year` 静态计算即可）。
- 顶部一个过滤输入框（原生 JS 过滤即可）。

### 5.5 国家详情 `/countries/[iso3]`

1. **档案头**：国旗（24×16）+ H1 中文名 + 英文名 + ISO3 + 币种（USD 计价区加标）+ 汇率（`1 CNY = x {币种}` 与 `1 {币种} = ¥y`）。
2. **优势摘要**：一行文字 + 标签列表：该国在哪些档位排全球第 1 / 前 3（默认口径）。没有则不显示该区块。
3. **SKU 表**（§6.6）：按产品线分组，组内按当前口径升序；筛选胶囊与产品线一致；`含历史快照 (+N)` 开关默认关。
4. 底部：`在矩阵中查看` 链接（带 `?q={iso3}`）。

### 5.6 变动记录 `/changes`

- 摘要行：最近检查时间、记录条数、涉及国家数、其中免费试用/首期优惠数。
- 默认 **按国家聚合**：每组一行摘要 `🏳 波兰 POL · 新发现 11 个 SKU（含 2 个免费试用）`，点击展开明细（档位中文说明、SKU、首期 → 续费、CNY）。用原生 `<details>` 实现。
- 存在两种或更多变动类型时提供类型筛选。明细主行显示 CNY 首期 → 续费，副行显示原币、优惠期数和适用的跳涨标记。

### 5.7 汇率与说明 `/rates`

1. **口径说明**（这页的核心价值是信任）：价格从哪来、刷新频率、CNY 如何折算、三种口径的公式、"活跃/历史快照"的含义、USD 计价区含义、跳涨倍数含义。用定义列表 `<dl>`，简洁。
2. 基准：`1 USD = x CNY`、汇率更新时间。
3. 汇率表：币种代码 / 中文名（如有）/ 1 USD 兑本币 / 1 本币折 CNY / 使用该币种的地区；顶部过滤框。移动端超过 4 个地区时折叠名单。
4. 免责声明完整版。

## 6. 组件规格

### 6.1 Price（价格文本）

- CNY：`¥` 前置，千分位，**始终 2 位小数**（`¥1,071.50`）。`intro` 口径首期为 0 时显示 `免费`。
- 原币：数字在前、ISO 代码在后、半角空格（`2,949.99 TRY`）。源数据为整数则不显示小数（`9,700 INR`），否则 2 位小数；必须先做定点舍入，杜绝浮点尾数。
- 一切数字：等宽字体 + `font-variant-numeric: tabular-nums`，表格内右对齐。
- 格式化函数集中在一个模块（如 `src/lib/format.ts`），全站复用，带单测。

### 6.2 DualPrice（双轨价格单元）

最核心的原子组件。结构（右对齐，两行）：

- 主行：当前口径的 CNY（Price-M），单位 muted `/月`；年付加 `年付` 小标。
- 副行（显示原币开启时）：有首期优惠 → `10 → 1,950 INR` + 优惠期数或试用时长 + TrapBadge；无优惠 → `2,949.99 TRY`。
- 状态：`best`（当前列表/列第 1）主价用 best 色 600，单元左侧 2px best 线 + best-bg 底；`top3`（第 2–3）仅 good-bg 底；`empty` 居中 `·`（muted）。
- 提示（tooltip / 移动端点击展开）：首期原币与期数、续费原币、首年月均拆解（`前 3 期 ¥2.16 + 后 9 期 ¥1,266.12 = 首年 ¥1,268.28，月均 ¥105.69`）、所用汇率。tooltip 用原生 `popover` 或轻量实现，不引入 UI 库。

### 6.3 TierCard（首页档位卡）

- 顶栏（subtle 底，40px）：左 = 档位短名（14px 600）+ muted 口径小标（如 `首期 ×3`、`35 国在售`）；右 = 当前口径最低价 `最低 ¥388.10`。
- 主体：Top 5 行，每行 `#排名（等宽 muted）｜ 国旗 + 中文名（+USD 小标）｜ DualPrice`。行高 44px（双行），整行可点 → 国家详情。
- 底栏（34px）：左 = 一句**数据驱动的提示**（仅在规则命中时出现，规则写在数据层并测试）：
  - 当前口径为 `intro` 且第 1 名的跳涨 ≥ 10 → `⚠ 首期最低但续费 ¥X/月，长期持有请看「首年月均」`（warn 色）；
  - 其余情况不显示提示。
    右 = `全部 {N} 国 →` 进入档位页。
- 每种口径各渲染一份排名（见 §4.3），只显示当前口径那份。

### 6.4 RankTable（档位排名表）

列：`排名 ｜ 国家/地区 ｜ 首期 ｜ 续费 ｜ 首年月均 ｜ 较最低`。

- 当前口径对应列表头加粗并带 `▲`，该列数值 600；其余两列 secondary。
- "较最低"：`+41%`（best 行显示 `最低`，大于 0 且小于 0.5% 显示 `<1%`）。
- **相对条**：当前口径列单元格背景叠加一条极淡（subtle 色）水平条，长度 = 该价 / 列表最高价，左起；条在文字之下，不影响对比度。
- 行 hover：hover 底色。行可点 → 国家详情。
- 移动端：只保留 `排名 ｜ 国家 ｜ 当前口径 DualPrice ｜ 较最低`。国名不折行，USD 小标在下一行。

### 6.5 Matrix（价格矩阵，Preact island）

- 列 = 数据层定义的比较档位（与首页卡片同一套），按产品线分两层表头：第一层产品线（上方 2px 墨色线），第二层档位短名（可点击排序，`aria-sort`），其下 muted 一行 `最低 ¥388 TUR`。
- 冻结：首列（国家，宽 168px：国旗 + 中文名 + ISO3 + 币种小字）吸附，桌面同时吸附两层表头。冻结列用 1px strong 线分隔。可继续向右滚动时，容器右缘显示轻微内阴影。
- 单元格：DualPrice 精简版（主 CNY + 副原币，不带 tooltip 外的 TrapBadge 文本，仅在有优惠时显示一个 warn/caution 色的 4px 小点），只在报价币种与市场币种不同时重复显示币种。列宽 134px，行高 44px（关闭原币时 34px），切换口径不改变尺寸。
- 每列第 1 名 best 态、第 2–3 名 top3 态（按当前口径与当前筛选结果计算）。
- 排序：点击列头 升序 → 降序 → 恢复默认（按国家中文名）；**空值永远排在最后**。
- 十字辅助：hover 单元格时整行 hover 底色 + 对应列头加深。
- 键盘：表头可 Tab 聚焦并 Enter 排序；焦点环可见。
- 性能：60 行 × 14 列直接渲染；排序和筛选使用 `useMemo`。Astro 传入原币金额、账期、优惠时长、汇率和排名。只渲染当前口径，打开弹窗时格式化明细。

### 6.6 CountrySkuTable（国家 SKU 表）

- 按产品线分组，组标题行（subtle 底）。
- 列：`档位说明 / SKU ｜ 首期（折月） ｜ 续费（折月） ｜ 首年月均 ｜ 状态`。SKU 可复制，CNY 带 `/月`，年付原币带 `/年`。
- 状态：当前口径达到档位全球最低的活跃 SKU（含同价别名）显示 `全球最低`。历史快照显示相应小标，首期原币超过续费另标 `源数据异常`。
- 来源技术名（`applecommerce_v26` 等）不直接展示，仅在 `title`/tooltip 中提供。

### 6.7 Flag

- 不使用 emoji 国旗（Windows 不渲染）。用 SVG 国旗文件，作为静态资源 `<img src="/flags/xx.svg" width="18" height="12" alt="">`（装饰性，国家名已有文字），1px `rgba(0,0,0,.08)` 内描边，`loading="lazy"`（首屏内的不 lazy）。只拷贝用到的 60 面。选用维护良好的开源国旗库（如 `flag-icons` 的 4x3 SVG），注意许可证。

### 6.8 控件

- 分段控件、开关、胶囊：高 30px，圆角 4px（胶囊 2px），1px default 边框；选中 = 墨色字 + strong 边 + surface 底。
- 输入框：高 32px，左侧 14px 放大镜图标，placeholder muted。
- 图标：只用到少量（搜索、外链、复制、菜单、箭头），使用 1.5px 线性风格（如 Lucide），按需内联 SVG，14/16px。

### 7.4 布局与形

- 4px 步进；内容最大宽 1280px（矩阵页可满宽）。
- 圆角：容器 4px、控件 4px、胶囊/徽章 2px。**禁用阴影**，仅浮层（吸顶条滚动后、tooltip、移动菜单）用一层极轻阴影。
- 分隔靠 1px 线与底色差，不靠卡片投影。
- 断点：`sm 640 / md 768 / lg 1024 / xl 1280`。

### 7.5 动效

排序、筛选、切换口径：0ms 瞬时。hover/展开：100–140ms ease-out，仅透明度/背景色。无入场动画。尊重 `prefers-reduced-motion`。

## 8. 可访问性与工程要求

- 表格使用语义 `<table>`/`<th scope>`/`aria-sort`；分段控件用 `role="radiogroup"` 或原生 radio；所有可交互元素键盘可达、焦点环可见（2px primary，offset 2px）。
- `<html lang="zh-CN">`；每页有独立 `<title>` 与 `description`；国家页/档位页标题含国家名/档位名（利于分享与搜索）。
- 性能预算：首页/档位页/国家页 JS（不含内联脚本）≈ 0；矩阵页 HTML < 400 KB，island 总 JS < 30 KB gzip；Lighthouse（移动）Performance / Accessibility / Best Practices / SEO ≥ 95；CLS ≈ 0。
- 组件放 `src/components/`，页面放 `src/pages/`，样式 tokens 放全局 CSS（Tailwind v4 `@theme` 映射到上面的 CSS 变量）。不要为每个小元素拆文件；一个组件文件包含它自身的子部件。
- 文案统一中文，标点用中文全角，数字与中文之间加空格。

### 8.1 SEO（与页面同期实现）

- 站点 URL 写在 `astro.config` 的 `site`（`https://googleone.laifuyou.com`），所有 canonical、sitemap、OG 链接由它派生。
- 每页：唯一 `<title>`（模板 `{页面主题} · G1 价目`）、`<meta name="description">`（含国家/档位名与最低价等具体数字，由数据生成）、`<link rel="canonical">`（不含 query）、Open Graph + Twitter Card（`summary_large_image`）。
- OG 图：v1 用一张站点级 1200×630 静态 PNG（按本规范视觉做：纸底、字标、一行标语），放 `public/`；不做每页动态生成。
- 结构化数据（JSON-LD）：全站 `WebSite`；首页与矩阵页 `Dataset`（name/description/dateModified=数据刷新时间/creator/license/variableMeasured）；国家页、档位页 `BreadcrumbList`。
- `@astrojs/sitemap` 生成 sitemap；`public/robots.txt` 指向 sitemap；`/404` 不入 sitemap。
- 语义化标题层级（每页唯一 H1）；国家页、档位页互相内链（国家页 → 其拿第 1 的档位页；档位页每行 → 国家页），形成可抓取的链接网。
- 带 `?view=`/矩阵筛选参数的 URL 必须 canonical 回无参数版本。
- favicon：SVG（朱砂方点 + G1）+ 180px apple-touch-icon PNG；`theme-color` 浅/深各一。

## 9. 反模式（禁止）

大 Hero / 插画 / 渐变 / 玻璃拟态 / 大圆角卡片堆叠 / 投影卡片；模仿 Google 品牌四色或 Material 风格；把 Excel 33 列原样搬上网页；只放大首期价而弱化续费；空格写"暂无/N/A/—"；emoji 国旗；浮点尾数与混用货币符号；历史快照与在售混排不加区分；引入重型图表库/UI 组件库/状态库；加载中文 webfont。

## 10. v1 不做（有需要再加）

多国勾选对比抽屉；用户自定义汇率并全站重算；矩阵列自定义显隐；手动深浅色切换；价格历史曲线（需要多次刷新的历史快照积累后再做）。
