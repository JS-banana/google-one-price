# 设计规范（v2）

[产品规范](product-v2.md)定义页面结构、计算与验收，本文补充交互和呈现。数据口径与刷新流程见[数据源](data-source.md)。

## 1. 页面原则

- 首屏直接给出可操作的条件和方案。首期优惠与续费并列，金额可查看原币、汇率与参考日期。
- 语义颜色用于付款条件、最低价与续费提示。空报价用 `·`，需要解释时用简短正文。
- 静态预渲染。首页决策器水合后恢复条件，其他页面使用原生交互。中文使用系统字体。

## 2. 价格呈现

- 决策器按持有期限累计实际付款，基准为所选地区的主线常规方案。账单以实际扣费月份为准。详见[产品规范 §3](product-v2.md#3-方案决策器首页核心)。
- 档位页、矩阵切换首期月价、首年月均和续费月价。年付折月参与排名，原币保留实际账期。国家的完整 SKU 表固定按首年月均排列，同时显示三种价格。
- CNY 千分位、前置 `¥`、固定两位小数。原币千分位，后置 ISO 代码，整数保留整数，其余保留两位。
- 档位与矩阵的跳涨标记，零元试用显示续费，1.2–10 倍用琥珀色，10 倍起用朱砂色。决策器推荐卡在续费金额旁显示跳涨或试用恢复原价。
- 美国以外的 USD 报价地区显示 `USD`。档位页和矩阵提供筛选开关及可见地区数。

## 3. 信息架构

| 导航       | 路由                              | 页面                                         |
| ---------- | --------------------------------- | -------------------------------------------- |
| 方案推荐   | `/`                               | 默认条件、推荐卡、同条件排行与分享           |
| 国家/地区  | `/countries`、`/countries/[iso3]` | 地区目录、付款条件、各产品最优方案、完整 SKU |
| 全量比价   | `/matrix`                         | 档位矩阵、移动端榜单和免费试用一览           |
| 避坑指南   | `/guide`、`/guide/[slug]`         | 指南目录与文章，标注复核日期及官方来源       |
| 数据与更新 | `/data`                           | 数据时效、计算口径、变动记录、汇率和免责声明 |

`/tiers/[tierId]` 保留为深链页，由矩阵列头、榜单和地区 SKU 表进入。档位页链接回相应产品的决策器。`/changes`、`/rates` 分别由 Astro 重定向到 `/data#changes`、`/data#fx`。404 页提供首页和国家搜索入口。

## 4. 全局外壳

- Header 高 52 px，桌面吸顶，导航当前项用墨色下划线。移动端用可展开菜单。
- Header 元信息链接到 `/data`，显示 `价格 N 天前 · 汇率 MM-DD`。价格观测相对时间在客户端计算，超过 30 天在 Header 下显示朱砂色提示。
- 页脚显示数据免责声明、价格观测时间、汇率日期、汇率来源和报价数量。
- 三口径切换只出现在矩阵和档位页。控制条同时提供原币开关，口径用 `?view=intro|year|renew` 覆盖已记忆的偏好。

## 5. 页面布局

### 5.1 首页

- H1 下方以原生单选、下拉和复选框设置需求、时长、订阅身份、人数、基准及礼品卡筛选。默认结果静态输出。
- 推荐区显示条件、基准与时效提示。桌面三列。移动端最省卡完整显示，稳妥和首付最低可从摘要展开。
- 每张卡列出付款标签、账单时间轴、适用的常规兜底价及可展开的订前检查。金额支持悬停或点击查看换算。
- 排行默认显示 10 个地区，可展开全部。地区档案链接能直接定位并高亮对应行。
- 下方给出跨区前须知、指南入口及复制方案链接和文字摘要。

### 5.2 地区与档位

- 地区目录按大区分组，支持按地区名、代码或币种过滤。目录项显示付款标签和进入全球前 3 的产品线数量。
- 档案头显示国旗、名称、币种、付款条件、官方来源和复核日期。下方给出默认条件下的 4 行方案、美国对比与优势，再显示完整 SKU 表。
- SKU 表按产品线分组，提供产品线筛选与历史开关。显示首期、续费及首年月均。异常历史记录带「源数据异常」标记。
- 档位页显示完整地区排名，当前口径的价格列加粗，最低价格单元带铜绿标记。末尾保留可复制的 SKU。

### 5.3 矩阵

- 双层表头按产品线分组，列头显示当前筛选的最低价。点列头在升序、降序和默认顺序之间循环，空值沉底。国家列与桌面表头冻结。
- 筛选包括国家搜索、大区和隐藏 USD 计价区。矩阵排序、档位选择与筛选同步到 URL。
- 桌面显示矩阵。移动端默认单档位榜单，可切换至横向滚动的矩阵。免费试用一览放在比价区之后。
- 单元格显示 CNY 和原币。报价可点击查看详情。列头及超长原币可换行。

### 5.4 指南与数据

- 指南目录按内容集合的顺序排列，文章展示正文、复核日期与官方来源。
- 数据页顶部提供区块跳转。变动记录按地区折叠，汇率表支持按地区或币种查找。

## 6. 组件

- 分隔和交互选中状态以边线与底色表达。控件约 30 px 高，主要表单可增加间距便于点击。
- 国旗为 18 × 12 px 装饰性静态 SVG。地区档案可使用 24 × 16 px。
- 金额细节用原生 popover 展示。价格与关键标记以文字传达语义，同时保持键盘焦点可见。

## 7. 视觉系统

### 7.1 色彩 Tokens（CSS 变量；深色模式跟随 `prefers-color-scheme`）

| token              | 浅色      | 深色      | 用途                                 |
| ------------------ | --------- | --------- | ------------------------------------ |
| `--bg-canvas`      | `#FAF8F4` | `#121311` | 页面底（暖纸白）                     |
| `--bg-surface`     | `#FFFFFF` | `#1A1C19` | 表格/卡片面                          |
| `--bg-subtle`      | `#F2EFE9` | `#232622` | 表头、卡片顶栏、分段控件底槽、相对条 |
| `--bg-hover`       | `#EDE9E0` | `#2B2F2A` | 行 hover                             |
| `--text-primary`   | `#181816` | `#EFECE6` | 主文字、主价格、交互选中态、焦点环   |
| `--text-secondary` | `#57534E` | `#A8A29E` | 次要文字、原币、表头                 |
| `--text-muted`     | `#8C867E` | `#7A766F` | SKU ID、时间戳、`·`                  |
| `--border-default` | `#E4DFD5` | `#2E312B` | 行分隔、外框                         |
| `--border-strong`  | `#C8C1B4` | `#44483F` | 表头底线、冻结列分界                 |
| `--best`           | `#0F766E` | `#2DD4BF` | 全球最低（铜绿）                     |
| `--best-bg`        | `#E6F4F1` | `#112A27` | 第 1 名底                            |
| `--good-bg`        | `#F2FAF8` | `#152220` | 第 2–3 名底                          |
| `--warn`           | `#C2410C` | `#FB923C` | 续费陷阱（朱砂）、品牌方点           |
| `--warn-bg`        | `#FFF0E6` | `#2D1B12` | 陷阱徽章底                           |
| `--caution`        | `#A16207` | `#FACC15` | 中度跳涨、USD 计价小标               |

规则：**不使用蓝色/紫色**；链接 = primary 色 + 下划线（`text-underline-offset: 3px`，默认 1px 下划线颜色为 border-strong，hover 变 primary）。语义不只靠颜色：best 总有 `#1`/`最低` 文本，warn 总有 `×N` 文本。文字对比度满足 WCAG AA。

### 7.2 字体

- 中文/界面：`"PingFang SC","Hiragino Sans GB","Microsoft YaHei UI","Noto Sans CJK SC",system-ui,sans-serif`，**不加载中文 webfont**。
- 数字/代码：`IBM Plex Mono`（自托管，仅 Latin 子集，400 + 600，woff2，`font-display: swap`，preload 600），回退 `ui-monospace, "SF Mono", monospace`。用于所有价格、汇率、ISO 代码、SKU、时间。

### 7.3 字号层级

| 角色        | 桌面                    | 移动  | 字重    |
| ----------- | ----------------------- | ----- | ------- |
| H1          | 22/30                   | 18/26 | 600     |
| H2 栏目     | 15/22（上 2px 墨线）    | 15/22 | 600     |
| 卡片标题    | 14/20                   | 14/20 | 600     |
| 推荐卡大价  | 24/30 mono              | 20/26 | 600     |
| 表格主价    | 13/18 mono              | 13/18 | 600     |
| 副价/元信息 | 11.5/16 mono            | 11/15 | 400     |
| 正文/国家名 | 13/18（说明段落 14/22） | 同    | 400–500 |

### 7.4 布局与形

- 4px 步进；内容最大宽 1280px（矩阵页可满宽）。
- 圆角：容器 4px、控件 4px、胶囊/徽章 2px。**禁用阴影**，仅浮层（吸顶条滚动后、tooltip、移动菜单）用一层极轻阴影。
- 分隔靠 1px 线与底色差，不靠卡片投影。
- 断点：`sm 640 / md 768 / lg 1024 / xl 1280`。

### 7.5 动效

排序、筛选、切换口径：0ms 瞬时。hover/展开：100–140ms ease-out，仅透明度/背景色。无入场动画。尊重 `prefers-reduced-motion`。

## 8. 可访问性、性能和 SEO

- 使用语义标题、原生表单和带行列标题的表格。全部交互可用键盘，焦点环为 2 px。375、768、1280、1600 px 无页面级溢出。支持系统深色模式。
- 首页 HTML < 250 KB，决策器新增 JS < 20 KB gzip。唯一框架 island 在首页。
- 所有页面有独立的 title、description、OG 和无查询参数的 canonical。全站提供 `WebSite`，首页与矩阵提供 `Dataset`，地区和档位提供 `BreadcrumbList`，指南文章提供 `Article`。
- sitemap 排除 404 和旧重定向路由。站点域名、canonical 及地图由 Astro 的 `site` 配置派生。
- v2 验收清单见[产品规范 §9](product-v2.md#9-验收)。
